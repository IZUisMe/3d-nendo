# 電子レゴ 実験プロトタイプ（M1〜M3）

カメラだけで手を使い、床のパーツを掴んで組み立て台にはめる操作が、軽量ノートPCで快適にできるかを確かめる実験用アプリです。
設計の決定事項は [DESIGN.md](DESIGN.md) を参照してください。

## 起動

```sh
npm install      # 依存関係 + MediaPipe の WASM と手検出モデル（約8MB）を取得
npm run dev      # https://localhost:5173 を Chrome で開く（証明書の警告は「詳細設定 → アクセスする」）
```

### スマホ（M4）

1. Windows の「設定 → ネットワーク → モバイルホットスポット」をオンにして、Android をそのWi-Fiにつなぐ（会場のWi-Fiが端末同士の通信を禁止していることが多いため）
2. 初回は Windows ファイアウォールの許可ダイアログで「プライベートネットワーク」を許可する
3. PC の開始画面で「スマホ」を選び、表示された QR コードを Android の Chrome で読み取る（警告は「詳細設定 → アクセスする」）。QR が読めない場合は、アドレス欄の候補を切り替える（ホットスポットは `192.168.137.1`）
4. スマホで「はじめる」→ 上端を画面に向けて持つ。ずれたら「中央に合わせる」

`npm install` 時にモデルが取得されなかった場合は、`node scripts/setup-assets.mjs` を実行してください。

## 実験の流れ

1. 参加者IDと操作方法（手／マウス）を選んで「開始」
2. 右上の見本と同じ形を、床のパーツ5個で組む（形が一致すると自動で終了）
3. 疲れ・イライラを5段階で答えて、JSON／CSV で書き出す
4. 途中でやめるときは Esc

## 操作

| 操作 | スマホ | 手 | マウス |
|---|---|---|---|
| 指す | 上端を向ける（傾き） | 人差し指の付け根 | ポインター |
| 掴む／置く | パッドを押す／離す | 親指と人差し指をつまむ／離す | 左ボタンを押す／離す |
| 回す（90°） | 押したままひねる、または ↺↻ ボタン | 掴んだまま手首をひねる | ホイール |
| 手応え | 指した・掴んだ・はまった・落ちた・回したときに振動 | なし | なし |

ひねりはどれもラチェット式で、一度回ったら元の角度付近に戻すまで次は回りません。

共通のキー: R 回す、Q・E 組み立て台を回す、H カメラ映像の表示切り替え、T 調整パネル、D 自由視点（開発用）

## 記録される項目

掴もうとした回数・成功回数、途中で落とした回数（見失い）、はめ損ね、台の外に落とした回数、回転の手段（ひねり／キー／ホイール）、所要時間、fps（1秒ごと）、手の検出時間、GPU名・CPUコア数などの環境情報、アンケート。

## 判定基準（DESIGN.md Q11）

掴む成功率が70%未満、または所要時間がマウスの3倍以上なら、スマホ操作（M4）に切り替えます。fps が30未満なら、先に軽量化してから測り直します。

## 構成

| ファイル | 役割 |
|---|---|
| `src/parts.ts` `src/grid.ts` | パーツ定義、マス目の判定（上から落として一番上の空き位置に積む） |
| `src/task.ts` | お題と一致判定 |
| `src/game.ts` | 掴む・運ぶ・はめるの状態管理 |
| `src/floor.ts` | 床のパーツの振る舞い（物理演算版に差し替えられる） |
| `src/input/` | 入力（手・マウス・スマホ）。どれも共通の `InputState` を出力する |
| `src/phone/` `phone.html` | スマホ側のコントローラー画面（傾きと掴み状態を送るだけ） |
| `server/relay.ts` | Vite に組み込んだ WebSocket 中継（`/relay`）と LAN アドレス取得（`/relay-info`） |
| `src/camera.ts` | カメラ映像の共有（将来の紙AR検出でも使う） |
| `src/world.ts` | 3D描画 |
| `src/log.ts` | 記録と書き出し |
| `src/config.ts` | 調整パネルで変えられる値 |

テスト: `npm test`

## 注意: 日本語を含むフォルダ名と Node 24

Node 24 の再帰的な `fs.rmSync` / `fs.cpSync` は、日本語を含むパスでクラッシュします（Windows、終了コード 0xC0000409）。そのため `npm run build` は先に `scripts/clean.mjs` で `dist/` を消してから Vite を動かします。フォルダ名を英数字にすれば、この問題は起きません。
